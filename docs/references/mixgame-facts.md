- **작성일**: 2026-09-01

- **원본 위치**: 로컬 `참고문서/` ([README](README.md))

> 이 문서는 **자료의 대체물이 아니다.** 문제의 정답을 정할 때는 원본을 다시 본다.

## 1. 베팅 구조 3종

| 구조 | 최소 | 최대 | 캡 |
|---|---|---|---|
| No Limit | BB | 스택 전부 | 없음 |
| Pot Limit | BB | **콜 금액 + 콜한 뒤 팟에 있는 금액** | 없음 |
| Fixed Limit | 정해진 벳 단위 | 같은 단위 (미니멈 레이즈만) | **1벳 + 4레이즈 = 5캡** |

- **팟리밋 계산** (가이드 p2~p4): "마지막 배팅을 콜 하는데 필요한 금액 + 마지막 배팅을 콜 한 후에
  팟에 있는 금액". 예 — SB/BB 10,000 에서 UTG 팟벳 = 10,000(콜) + 10,000 + 10,000 + 10,000 = **40,000**.
  이어서 MP 팟벳 = 40,000(콜) + 10,000 + 10,000 + 40,000 + 40,000 = **140,000**.
- **앤티**: "PLO 토너먼트에서 Ante 금액은 프리플랍 팟 계산에서 **제외**되는 것이 보편적이나
  대회사마다 다를 수 있습니다" (가이드 p5). → **기본값은 제외.** 문제 해설에 이 단서를 붙인다.
- **픽스리밋 2배 지점**: 플랍게임은 턴부터, 드로우게임은 **3번째 베팅 라운드**부터,
  스터드는 **5th street** 부터 (가이드 각 게임 절).
- **캡 예외**: 토너먼트 최종 2인부터는 **무제한** 레이즈, 양쪽 올인 선언 허용 (프로토콜).
- "I bet the pot" 선언은 리밋·노리밋에서 **유효한 벳이 아니다.** 다만 최소 벳·레이즈를 채울
  의무는 지운다 (프로토콜).

## 2. 게임별 사실 (`GameSpec` 필드 단위)

### 7-Card Stud — `family: stud` · `fixed-limit`

| 필드 | 값 | 출처 |
|---|---|---|
| 강제 베팅 | **앤티 + 브링인** (SB/BB 없음) | 가이드 p7 |
| 초기 딜 | 3장 — 다운 2 + **업 1(도어카드)**. 3장 주고 고르는 방식이 아니다 | 가이드 p7 |
| 베팅 라운드 | **5회** (3rd·4th·5th·6th·7th) | 가이드 p7 |
| 3rd 첫 액션 | **가장 낮은 업카드** = 브링인. 브링인 금액을 내거나 컴플리트 | 가이드 p8 |
| 4th 이후 첫 액션 | **가장 높은 업카드** | 가이드 p8 |
| 4th 벳 크기 | 스몰벳. 단 **업카드에 페어가 있으면 빅벳 선택 가능** | 가이드 p8 |
| 5th~7th | 전부 빅벳 | 가이드 p8 |
| 번카드 | 매 스트릿 딜 **전에** 내린다 | 가이드 p7 |
| 7th | 페이스 다운 | 가이드 p8 |
| 7th 스텁 부족 | 테이블 중앙에 **커뮤니티 카드 1장** — 전원 공용 | 가이드 p8 · 프로토콜 |
| 승자 판정 | 7장 중 최고 5장. 족보는 홀덤과 동일 | 가이드 p7 |

- **컴플리트는 첫 벳으로 간주한다** (프로토콜).
- 가이드 p7 의 "3장은 뒤집어서, 4장은 뒤집어서"는 **오타**로 보인다(같은 말이 두 번).
  실제는 다운 3장(1st·2nd·7th) + 업 4장(3rd~6th). **인용 전 원본 확인 필요.**

### Stud Hi/Lo Regular — `family: stud` · 자격 없는 로우

7-Card Stud/8 의 규칙을 전부 따르되 (프로토콜):

- 로우에 **8-or-better 자격이 없다**
- 첫 라운드 첫 액션 = **가장 높은 업카드, 동률은 무늬로** — **스페이드 K 가 최고**
- 이후 라운드 첫 액션 = **가장 낮은 핸드**
- 7th 스텁 부족 시 **커뮤니티 카드를 쓰지 않는다.** 스텁 + 먹 + 번을 합쳐 컷하고 번 후 다운으로 배분

### 2-7 Triple Draw — `family: draw` · `fixed-limit`

| 필드 | 값 | 출처 |
|---|---|---|
| 강제 베팅 | 블라인드 (SB = 버튼 왼쪽) | 가이드 p6 |
| 홀카드 | 5장 | 가이드 p6 |
| 베팅 / 드로우 | 베팅 **4회** · 드로우 **3회** | 가이드 p6 |
| 첫 액션 (프리드로우) | BB 왼쪽 | 가이드 p6 |
| 드로우 순서 | **버튼 왼쪽(SB)부터** 장수 확인 → 번 1장 → SB 부터 회수·배분 | 가이드 p6 |
| 2배 지점 | **3번째 베팅 라운드부터** | 가이드 p6 |
| 로우 판정 | 로우볼 — **A 는 최고**, 스트레이트·플러시 **인정**. 최고 핸드 = 7-5-4-3-2 무플러시 | 가이드 p5~6 |
| 팻(Pat) | 교체 안 함. 다음 라운드에 다시 바꿀 수 있다 | 가이드 p6 |

- **50% 규칙** (가이드 p6): 올인 금액이 레이즈 금액에 못 미칠 때 **50% 미만은 콜, 50% 이상은 레이즈**로
  처리하고 캡이 그만큼 올라간다.
  - 예1 — 1,000/2,000 에서 A 레이즈 4,000 → B 올인 5,500 → C 레이즈 7,500, 캡 **9,500**
  - 예2 — A 레이즈 4,000 → B 올인 4,500(50% 미만) → C 레이즈 6,000, 캡 **10,000**
  - 가이드 자체가 "대회사마다 다르므로 플로어 호출 권장"이라고 단서를 단다.
  - **축 2 의 미완성 유형(제29조 3항 50% 규칙)과 같은 판정이다.** 엔진에 한 번 넣으면 두 축이 쓴다.
- 회수한 카드는 드로우 라운드가 끝날 때까지 먹과 섞지 않는다.

### 2-7 Single Draw — `family: draw` · `no-limit`

베팅 **2회** · 드로우 **1회**. 그 외 진행은 트리플드로우와 같고 베팅만 노리밋 홀덤과 동일 (가이드 p6).

### Badugi — `family: draw` · `pot-limit` 또는 `fixed-limit`

| 필드 | 값 |
|---|---|
| 홀카드 | **4장** |
| 베팅 / 드로우 | 베팅 4회 · 드로우 3회 |
| 목표 | 페어 없고 무늬 겹치지 않는 낮은 4장. 최고 = 무늬 다른 **A-2-3-4** |
| 랭크 | **A 가 최저**, K 가 최고 |
| 불완전 핸드 | 무늬/숫자가 겹치면 3장(원베이스) → 그만큼 약하다 |
| 2배 지점 | 픽스리밋일 때 3번째 베팅 라운드부터 |

(가이드 p6~7)

### PLO — `family: flop` · `pot-limit`

홀카드 4장, 쇼다운에 **홀 2장 + 보드 3장 강제**. 족보는 홀덤과 동일. 블라인드. (가이드 p4~5)
딜러는 팟 금액을 알려줄 수 있고, 팟을 카운트해 두는 것도 허용된다.

### PLO8 (Omaha Hi/Lo 8-or-better) — `family: flop` · `pot-limit`

- Hi 는 홀덤과 동일, **Lo 는 A-5 로우에 8 이하만 인정**
- 보드에 8 이하가 **3장 이상**이어야 로우가 성립한다
- Hi/Lo 각 절반씩. 로우 성립자가 없으면 Hi 가 전부 가져간다
- **홀칩은 Hi 승자에게** 준다
- 헤즈업은 스플릿이 잦아 **벳을 팟으로 수거하지 않고 각자 앞에 두는 것을 권장**

(가이드 p5)

## 3. 예외 처리 (프로토콜)

### 노출 카드

| 상황 | 처리 |
|---|---|
| 스터드 초기 딜 노출 | 그 카드가 그 플레이어의 **업카드**가 된다. 다운 2장이 노출되면 **미스딜** |
| 스터드 7th(다운) 노출 | 남은 사람들에게 다운을 마저 돌리고, 노출 카드는 **스텁에 섞은 뒤** 맨 위에서 다시 다운으로 준다 |
| 드로우 초기 딜 노출 | 카드를 교체하고 노출 카드는 **번카드**가 된다. 두 번째 노출은 **미스딜** |
| 드로우 라운드 노출 | 그 라운드의 **디스카드로 취급**. 전원 드로우가 끝난 뒤 교체한다. 2장 이상이면 전부 돌린 뒤 순서대로 교체 |

### 스텁 부족

- **스터드**: 번카드를 섞어 쓰거나 TDA 대로 7th 를 커뮤니티 카드로. 스텁의 마지막 카드로 딜이
  완결되면 그대로 써도 된다. **Hi/Lo Regular 만 예외** — 커뮤니티 없이 스텁+먹+번 합쳐 컷·번 후 다운.
- **드로우**: 딜러는 교체 장수 선언이 끝나면 스텁 장수를 (노출 위험 없이) 파악해야 한다.
  스텁 부족 → 스텁 + 번 리셔플 → 그래도 부족하면 **이전 라운드의 먹**까지 섞는다.
  **현재 라운드의 디스카드는 섞지 않는다** (첫 드로우를 완결할 수 없을 때만 예외).
  리셔플 후에는 완료된 드로우 라운드 수만큼 번카드를 무작위로 뽑는다.
  스텁의 마지막 카드는 **어느 드로우에나** 쓸 수 있다.

### 스터드 개정 사항

- **업카드 순서를 고의로 바꾸면** 핸드가 데드로 선언될 수 있다 (TD 재량)
- 업카드가 될 카드가 다운으로 갔는데 식별 가능하면 뒤집는다. 다른 다운카드와 섞여 식별
  불가능하면 **플로어가 홀카드 3장을 섞어 무작위로 한 장을 업카드로** 뒤집는다
- 잘못된 플레이어가 브링인/컴플리트했을 때: **다음 사람이 아직 액션하지 않았으면** 칩을 회수하고
  정정한다. **이미 액션했으면** 그 벳이 유효하고, 진짜 최저 카드는 의무가 없어진다

### 드로우 개정 사항

- 5카드 드로우는 **6핸드 권장** (7핸드도 허용하나 권장하지 않음)
- **교체 장수 구두 선언은 구속력이 있다.** 순서를 어긴 선언이어도 장수는 바꿀 수 없다.
  다만 새 카드를 받기 전이라면 **버릴 카드 자체는** 바꿀 수 있다
- 5장 전부 바꾸면 5장을 연속으로 준다

### 밸런싱

스터드 종목이 **하나라도 포함된** 이벤트에서는, 지금 진행 중인 게임이 스터드가 아니어도
**하이카드 드로우로 이동자를 정한다** (프로토콜).

## 4. 게임 전환 (참고 — 지금은 도입하지 않는다)

프로토콜에 확정 규칙이 있다: 레드·그린 버튼, 그린이 레드를 따라잡으면 게임 전환,
테이블 **최대 좌석 수만큼** 각 게임, 3인 이하부터 6핸드씩, 딜러스초이스는 두 버튼이 함께
간 플레이어가 다음 게임을 고른다.

**PRD §6-3 대로 믹스 모드의 전환 주기는 프로토타입에서 정한다** (2026-09-01 결정).
이 규칙은 참고로만 둔다.

## 5. 자료에 없는 것 — 짐작으로 채우지 마라

- **Razz · Stud Hi/Lo 8 · A-5 Triple Draw** 의 단독 설명이 없다. 7-Card Stud + 로우볼 설명으로
  유도는 되지만 **원문 근거가 아니다.** 3단계(평가기 2종)에서 필요해지면 자료를 더 받아야 한다.
- 가이드 p3·p4 의 팟 계산 예시 **그림**은 이미지라 읽지 못했다 (텍스트 설명은 §1 에 옮겼다).
- KakaoTalk `_02` 하단의 **"Stud / (GAME) (BRING-IN) (First Action)" 표**가 잘려 있다.
  스터드 종목별 브링인·첫 액션의 정본이 될 자료라 전체 이미지가 필요하다.
