## 이 레포에서 반드시 지킬 것

1. **정답은 엔진이 낸다.** 화면 코드에 규칙 판정을 쓰지 마라. 쓰고 싶어지면 엔진이 부족한 것이다
2. **시드 결정론.** 생성기 안에서 `Math.random()` 을 한 번이라도 쓰면 시드가 무의미해진다
3. **불변.** 리듀서와 순수 함수는 입력을 절대 뮤테이트하지 않는다
4. **판정에 표시 라벨을 쓰지 마라.** `spec.betting` 코드값으로 갈라라 — `spec.labels.*` 는 화면 전용이다
5. **자료에 없는 것을 짐작으로 채우지 마라.** 없으면 물어보고, 답을 받으면 출처를
   `사용자 확인 (날짜)` 로 적어라
6. **실제 브라우저에서 눈으로 봐라.** 렌더·플레이로만 잡히는 결함이 매번 나온다
7. **완료는 실행 출력으로만 주장한다**
8. **말투를 검사하라.** 이름 뒤 조사는 붙여 쓴다(`4번이다`), 명령형은 「…하세요」로 통일한다.
   영어 직역·번역투가 계속 새어 나왔다
