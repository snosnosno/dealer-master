# 카드 에셋 출처

## 덱

- **이름**: English pattern playing cards
- **작가**: Dmitry Fomin (Дмитрий Фомин)
- **라이선스**: **CC0 1.0** (퍼블릭 도메인 기증) — 상업 이용·수정·재배포 자유, 표기 의무 없음
- **출처**: Wikimedia Commons, 파일명 `English pattern <랭크> of <무늬>.svg`
- **받은 날**: 2026-08-31
- **확인 방법**: Commons API `imageinfo.extmetadata.LicenseShortName` 로 52장 전건 조회 —
  전부 `CC0`. 스크립트가 아니라 API 응답으로 확인한 것이다.

표기 의무는 없지만 출처를 남긴다. 나중에 "이 그림 어디서 났나"를 다시 증명해야 할 때
이 파일이 근거가 된다.

## 만드는 법

```
python build-card-sprite.py <원본디렉터리> cards.sprite.svg
```

원본 파일명은 랭크+무늬 두 글자 (`AS`, `TD`, `2C` …). 원본 52장 2,315,812 bytes →
스프라이트 1,588,565 bytes (69%). 줄어든 건 대부분 Inkscape 가 남긴 좌표 자릿수와
줄바꿈이고, 그림 자체는 손대지 않았다.

`<symbol id="c-AS" viewBox="0 0 360 540">` 형태로 들어간다. 원본 캔버스가 360×540 이라
**가로세로비가 1.5** 다 — 카드 박스를 1.42 로 잡으면 그림이 눌린다.

## 안 쓴 것

- **카드 뒷면**: Commons `Card back 01.svg` 는 LGPL 이라 뺐다. 지금 뒷면은 CSS 로 그린 것이다.
- **실제 카드 브랜드 뒷면**(KEM·Copag·Modiano 등)은 트레이드 드레스라 베끼면 안 된다.

## 알아둘 것 — 작은 크기에서의 가독성

이 덱은 실물 비율의 표준 인덱스다. 실측(2026-08-31, 헤드리스 렌더):

| 렌더 크기 | 결과 |
|---|---|
| 19px (좁은 화면 홀카드) | 랭크 인덱스가 거의 안 읽힌다. 그림카드는 색 얼룩 |
| 25px (넓은 화면 홀카드) | 인덱스는 읽히고, 그림카드는 "그림카드"인 것만 구분된다 |
| 33px (보드) | 문제없다 |

판독 속도가 곧 점수인 게임이라 이건 그냥 넘길 문제가 아니다.
