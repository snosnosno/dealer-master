# 카드 에셋 출처 (앱 배포본)

## 덱

- **이름**: English pattern playing cards
- **작가**: Dmitry Fomin (Дмитрий Фомин)
- **라이선스**: **CC0 1.0** (퍼블릭 도메인 기증) — 상업 이용·수정·재배포 자유, 표기 의무 없음
- **출처**: Wikimedia Commons, 파일명 `English pattern <랭크> of <무늬>.svg`
- **받은 날**: 2026-08-31
- **확인 방법**: Commons API `imageinfo.extmetadata.LicenseShortName` 로 52장 전건 조회 —
  전부 `CC0`. 스크립트가 아니라 API 응답으로 확인한 것이다.

표기 의무는 없지만 출처를 남긴다. 나중에 "이 그림 어디서 났나"를 다시 증명해야 할 때
이 파일이 근거가 된다.

## 만드는 법

```
python build-card-sprite.py <원본디렉터리> cards.sprite.svg
```

원본 파일명은 랭크+무늬 두 글자 (`AS`, `TD`, `2C` …). 원본 52장 2,315,812 bytes →
스프라이트 1,588,565 bytes (69%). 줄어든 건 대부분 Inkscape 가 남긴 좌표 자릿수와
줄바꿈이고, 그림 자체는 손대지 않았다.

`<symbol id="c-AS" viewBox="0 0 360 540">` 형태로 들어간다. 원본 캔버스가 360×540 이라
**가로세로비가 1.5** 다 — 카드 박스를 1.42 로 잡으면 그림이 눌린다.

## 안 쓴 것

- **카드 뒷면**: Commons `Card back 01.svg` 는 LGPL 이라 뺐다. 지금 뒷면은 CSS 로 그린 것이다.
- **실제 카드 브랜드 뒷면**(KEM·Copag·Modiano 등)은 트레이드 드레스라 베끼면 안 된다.

## 알아둘 것 — 작은 크기에서의 가독성

이 덱은 실물 비율의 표준 인덱스다. 실측(2026-08-31, 헤드리스 렌더):

| 렌더 크기 | 결과 |
|---|---|
| 19px (좁은 화면 홀카드) | 랭크 인덱스가 거의 안 읽힌다. 그림카드는 색 얼룩 |
| 25px (넓은 화면 홀카드) | 인덱스는 읽히고, 그림카드는 "그림카드"인 것만 구분된다 |
| 33px (보드) | 문제없다 |

판독 속도가 곧 점수인 게임이라 이건 그냥 넘길 문제가 아니다.

**대응(2026-08-31)**: 홀카드 최소 크기를 19 → **24px** 로 올리고, 그만큼 좌석 패딩(4→2px)과
홀카드 간격(3→2px)을 줄여 360px 화면에 맞췄다. 360px 실측으로 가로 넘침 없음 확인.
카드 박스 세로비도 1.42 → **1.5**(원본 캔버스 360×540)로 맞췄다 — 안 맞추면 그림이 눌린다.

## 앱 배포 형태 (2026-08-31)

프로토타입은 스프라이트 하나를 문서에 인라인했지만(`file://` 제약), **앱은 개별 파일 52장**을
`app/public/cards/<랭크><무늬대문자>.svg` 로 둔다. `docs/superpowers/prototypes/assets/split-card-sprite.py`
가 스프라이트에서 뽑아낸 것이다.

이유 둘:

1. **외부 SVG 를 `<use>` 로 부르는 것을 Chromium 이 지원하지 않는다.** 스프라이트를 쓰려면
   JS 로 받아 DOM 에 주입해야 하고, 그건 "인라인 1.6MB 금지"를 우회로 되살리는 것이다
2. 전송량 — 스프라이트는 첫 화면에 gzip 303KB 를 전부 낸다. 개별 파일은 한 문제에 실제로
   뜬 카드만 받는다 (문제당 최대 15장 ≈ gzip 100KB, 카드 1장 평균 6.5KB)

**분리하면서 고친 것**: `build-card-sprite.py` 가 `xmlns:inkscape` 선언을 지웠는데 Inkscape
편집 노드(`<inkscape:path-effect>`)가 접두사를 그대로 쓰고 있었다. 스프라이트는 HTML 안에
인라인돼서 관대한 HTML 파서가 넘어갔지만, **개별 .svg 는 엄격한 XML 로 파싱된다** — 52장 중
41장이 파싱 실패였고 `<img>` 였다면 전부 빈 칸이었다. 그리기에 쓰이지 않는 노드라 걷어냈고,
분리 스크립트가 파일마다 XML 파싱을 통과하는지 확인한다.

**렌더 확인 (2026-08-31, Chromium)**: 13장 × 24px·33px 로드 — 깨진 이미지 0, 종횡비 1.5 유지.

## 음향

**외부 에셋을 쓰지 않는다.** 네 효과음(카드 슬라이드·칩·타이머 틱·정답/오답)은
`app/src/lib/rush/sound.ts` 가 WebAudio 로 합성한다. 전송량 0바이트고 라이선스 근거가 필요 없다.
