## 0. 먼저 할 것 — ECC

이 작업은 **ECC(Everything Claude Code, `affaan-m/everything-claude-code`)** 로 진행한다.

1. ECC 가 이 세션에 있는지 확인한다(`/plugin` 목록 · 사용 가능한 스킬/명령에 `everything-claude-code:` 접두어가 있는지).
2. 없으면 **멈추지 말고** 사용자에게 한 줄로 알린 뒤 같은 흐름을 기본 도구로 밟는다 —
   설치는 사용자가 로컬 Claude Code 에서 `/plugin marketplace add affaan-m/everything-claude-code` →
   `/plugin install everything-claude-code@everything-claude-code` 로 한다(클라우드 세션에서는 Claude 가 설치할 수 없었다).
3. 단계마다 ECC 흐름을 지킨다: **계획(plan) → 구현 → 검증(자동 플레이 테스트 · 스크린샷) → 코드 리뷰(리뷰 에이전트) → 커밋 · 게시**.
   ECC 명령 이름은 설치된 버전에서 확인한다(예: `/everything-claude-code:plan`). 짐작한 명령을 쓰지 않는다.

## 3. 할 일 — 사용자가 고른 순서대로 (단계마다 테스트 → 커밋 → 같은 링크로 게시)

### ③ 돌발 이벤트 (막 시작하려던 참 — 코드는 0줄)
할 일 목록에 `kind: 'event'` 를 추가한다: `{ type, title, desc, ic, pos, on(task), onTimeout(), limit }`. 누르면 점장이 `pos` 로 걸어가 도착 시 `on`.
하루 1~2건(토 +1, 1일차는 쉬운 것 1건)을 영업 중 무작위 시각에 예약.
- **단체 손님** — 6명이 연달아 도착(줄 넘침 압박)
- **인플루언서** — 보라 고리 VIP. 나갈 때 만족 ≥70 이면 평판 +5, 아니면 −4
- **정전** — 조명이 어두워지고 테이블 정지. 벽의 **차단기**(새 메시)까지 걸어가야 복구. 30초 넘기면 이탈 · 평판 −3
- **딜러 다툼** — 두 딜러 😠. 테이블로 가서 선택: 조용히 중재(권장) / 한 명 휴식 보내기 / 공개적으로 꾸짖기 — ④의 사기와 연결
- **칩 환전 요구** — 손님이 「칩을 현금으로 바꿔 달라」. 선택: **거절하고 설명(정답)** / 현금으로 바꿔 준다 / 상품권으로 대신 준다. 틀리면 「불법 환전 신고」 벌금 · 평판 큰 감점. 해설은 「칩의 현금 · 현금성 상품 교환은 불법 소지가 크다 — 우리 펍은 참가비와 음료로만 운영」 정도로, 법 조항을 단정하지 않는다
- **취객 소란** — 바 손님 🍻. 가서 진정시키기, 놓치면 주변 만족 −10
- **위생 점검** — 12초 예고 후 점검원 등장. 그때 바닥이 젖어 있으면 벌금 20만 · 평판 −2, 깨끗하면 +1

### ④ 직원 깊이
- **특성** 6종(직원 · 지원자에 0~1개): 손이 빠름(속도 +15%) · 꼼꼼함(정확도 +5) · 수다쟁이(서빙 만족 +, 느림) · 지각 잦음(출근율 −8%p) · 멘탈 약함(자기 테이블 오판정 때 사기 −8) · 분위기 메이커(주변 만족 서서히 +)
- **사기(morale) 0~100**, 저장. 과로(피로 35↑ 오래) −, 칭찬(하루 1회, 테이블 정보 · 🧑‍💼 창) +8, 일요일 휴무 +6, 일당 인상 +15. 사기 60 미만이면 정확도 · 속도 감소, 35 미만이면 노쇼 확률 +15%p, **20 미만이면 마감 때 그만둔다**
- **일당 인상 요청** — 사기 45 미만 직원이 다음 오픈 준비에서 요청(수락 사기 +20 / 거절 −15)
- **교육 트리** — 판정(실질 액션 퀴즈) · 속도(칩 세트 합 퀴즈) · 응대(손님 응대 선택 퀴즈) 각 0~3단계, 하루 한 번. 3문제 중 2개 이상 맞히면 +1단계. 판정 2단계 이상 = **믹스게임 자격**(⑥)

### ⑤ 매장 꾸미기
- 테마 구매 · 전환(클래식 · 네온 · 라운지 — 바닥 · 벽 · 조명 색, 네온은 띠 조명)
- 장식 구매(화분 · 소파 · 아트월 · **트로피 진열장** — 누적 우승 수만큼 트로피가 쌓인다) → 오픈 준비 「꾸미기」 탭 → **배치 모드**: 바닥 탭으로 놓기, 놓인 것 탭으로 회수. 테이블 · 카운터 · 동선 근처 금지
- 장식 반경 3 안의 손님 만족이 서서히 오른다 → **배치 위치가 의미 있게**. 위치는 저장

### ⑥ 테이블 깊이
- `nlh-table.html` 의 족보 평가기를 옮겨, 핸드 끝마다 실제 보드 5장 + 남은 사람 홀카드로 **승자를 정한다**(지금은 무작위). 보드를 테이블 위 카드 면(캔버스 텍스처 52장 캐시)으로 보여 주고, 가끔 「♠ 플러시!」 말풍선. 팟 이동도 실제 승자 쪽으로
- 상점 **믹스게임 테이블(PLO8)** — 2번 테이블 전환. 믹스 자격 딜러가 없으면 사고 확률 2배 · 오픈 때 경고. 고수 손님 비율 ↑, 착석 때 믹스 참가비 +1만
- 판정 사고는 **원문 대조를 마친 것만** 늘린다 — 짐작으로 규칙을 만들지 않는다

### ⑦ 그래픽 · 사운드 (외부 서비스 없이 자체 생성)
- 캐릭터: 머리카락(색 다양) · 눈 · 팔, 딜러 나비넥타이
- WebAudio 라운지 배경음악(Cmaj7–Am7–Dm7–G7 패드 + 워킹 베이스, 작게) · 손님 수에 비례하는 웅성거림 · 🎵 토글(🔊 는 효과음)

## 4. 지켜야 할 것

- **합법 운영**: 매출은 참가비 · 음료(· 예약 보증금)뿐. 시상은 트로피 · 시드권. 칩 환전 · 현금 시상은 게임 안에도 없다. 직원 채용에 실제 구인 · 매칭 표현을 쓰지 않는다
- **판정 근거**: TDA 케이스 문서 기반, 원문 대조 전이라 채점 화면에 「원문 확인 전」. 원문 확인 안 된 규칙은 출제하지 않는다(새 손님의 버튼~BB 사이 착석 · 헤즈업 · 밸런싱 이동 좌석)
- **사용자가 좋아한 것**: 직접 걷기 · 레벨마다 정시 아나운스 · 세팅 단계 · 공부가 되는 퀴즈 · 연출. **싫어한 것**: 너무 바쁨(직원 위임으로 풀었다) · 말풍선이 가림(잡담 3개 제한 · 💬 끄기) · 답이 화면에 보이는 것(HUD 에 블라인드 금액 · 레벨 번호를 띄우지 않는다)
- 모바일 우선(세로 화면 카메라 · 하단 할 일 목록). `prefers-reduced-motion` 존중. 색은 토큰 + 다크 모드
- 시간 정지 중(모달)엔 시뮬레이션이 멈춘다. 효과(`stepFx`)는 실시간
- UI 문구는 한국어, 짧고 구체적으로. 커밋 메시지도 한국어(레포 관례)

## 5. 검증 · 게시 절차

```bash
cd pub-sim
node -e "new Function(require('fs').readFileSync('game.js','utf8'))"   # 문법
node tools/autoplay.js 2 perfect shot     # 이틀 자동 플레이(약 5분) — errors 가 [] 여야 한다. 10분 제한을 넘기지 않게 일수를 정한다
node tools/weekend.js                     # 토요일 · 예약 · 주간 정산 → 2주차
node tools/noshow.js                      # 노쇼 · 대타 (무작위가 섞여 결과가 매번 조금 다르다)
python3 tools/build-artifact.py <스크래치패드>/pub-artifact
```

게시: Artifact 도구로 `<스크래치패드>/pub-artifact/index.html` 을 publish, `files` 에
`{"game.js": "<레포>/pub-sim/game.js", "vendor/three.min.js": "<레포>/pub-sim/vendor/three.min.js"}`,
**url 은 위 링크**(같은 링크를 유지 — 새 대화에서는 먼저 `action: "read"` 로 읽은 뒤 `url` 로 게시). 단계마다 `label` 을 「8판 — 돌발 이벤트」처럼.

새 기능의 자동 점검은 `window.__pub`(= `G`)를 통해 한다. 정답 처리용으로 `G.current` 에 열린 문제와 `correct` 를 넣는 관례를 지킨다.
